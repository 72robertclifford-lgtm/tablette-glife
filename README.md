# Tablette GLife

Tablette du serveur GLife : chaque appli ouvre le site d'une entreprise en plein écran.

## Ajouter ou modifier une appli pour tout le monde
Modifie le fichier `apps.json` sur GitHub (icône crayon), puis « Commit changes ».
Chaque appli : `label` (nom), `url` (lien du site), `color` (couleur de l'icône), `icon` (lien d'image, optionnel).
Le site se met à jour tout seul une minute après.

## Espace admin
Bouton « Admin » sur l'accueil. Les applis ajoutées depuis l'espace admin ne sont gardées
que dans le navigateur de la personne qui les ajoute. Pour une appli visible par tous, passe par `apps.json`.
